## Evidence and effective defaults

[operator-defaults.json](operator-defaults.json) records full resolved snapshots for compat/test/enterprise/production/strict with an explicit development environment, plus production profile with production environment, exact source hashes, runtime, command and working directory. [scripts/operator-defaults.mjs](scripts/operator-defaults.mjs) imports only configuration and reads reviewed source files. It starts no runtime, collector, service, receiver or process manager, and creates no illustrative output root. It executed successfully on Node v24.21.0 / darwin x64; it is configuration evidence, not Node 22 runtime qualification.

The default profile is `compat`, environment `development`, service `rawnode`. A profile name alone does not set the environment, storage durability, or deployment authorization. The optional `/config` environment reader and Foundation provider are separate entry points; do not silently import ambient production settings into a test.

## Qualification scope and performance

The mandatory local scope is exact-archive source/extracted/offline-installed package correctness, Node22.0.0 floor and retained24.21.0 runtime evidence, strict public types/all exports/basic example/HTTP-security, fresh native Studio controls and lifecycle, and the pinned Monitor/PM pair. Independent gate results must remain visible if a mandatory browser or runtime gate is incomplete.

Native Linux, native Windows, arm64, additional browser/assistive-technology families and service deployments are configuration-specific **UNRUN** profiles unless separately selected and authorized. They are not silently certified by macOS x64 or PM fixtures, and they are not universal prerequisites for this local scope. WSL is Linux, not native Windows. [SERVICE_SCOPE.md](SERVICE_SCOPE.md) gives the later handoff requirements.

No new overhead experiment is required by the legal/metadata/documentation and external qualification-harness changes in this run; no monitored hot path was changed for those edits. The [October25 overhead summary](../../readiness-2026-10-25/overhead-summary.json) and [raw experiment](../../readiness-2026-10-25/overhead.json) remain historical characterization of their recorded Node24/archive:20,000 operations, fixed labels,10% trace sampling,512 queue slots,batch128,one in-flight batch,2 ms sink delay, explicit GC and allocation profiling. They showed substantial instrumented workload overhead, not a zero-overhead promise, leak verdict, production soak or approved capacity. No production budget was supplied; do not invent one after measurement. A later changed hot path or approved workload promise would require a fresh predeclared comparison.
