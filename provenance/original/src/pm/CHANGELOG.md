# Changelog

## 0.1.0 — 2026-07-14

- Added standalone RawNode PM supervisor daemon.
- Added fork, cluster, and external process drivers.
- Added readiness-gated rolling reload, scaling, graceful drain, and bounded shutdown.
- Added restart backoff, restart-window quarantine, desired-state persistence, and resurrection.
- Added encrypted state, authenticated control socket, audit journal, secret redaction, and diagnostics.
- Added bounded log capture, telemetry, Prometheus formatting, file watching, terminal monitoring, and realtime subscriptions.
- Added optional HTTP management and SSE endpoints.
- Added RawNode runtime provider, adapter, commands, exact-anchor integrator, and process manifest template.
- Added systemd and launchd startup generators.
- Added first-party declarations and behavioral validation suite.
