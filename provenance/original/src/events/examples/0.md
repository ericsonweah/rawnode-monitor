# 2. **Architecture Overview**

## High-level flow

```text
HTTP / WS / TCP / UDP / CLI / Domain Service
                       │
                       ▼
             app.resolve('events')
                       │
                       ▼
            AdvancedEventDispatcher
                       │
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
   Exact event    Hierarchical     Glob pattern
    listeners      wildcards        listeners
        │              │              │
        └──────────────┼──────────────┘
                       ▼
                 onAny listeners
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
       Context       History     Metrics/diagnostics
          │
          ├── Local synchronous dispatch
          ├── Local awaited dispatch
          ├── Bounded deferred dispatch
          ├── In-process job queue
          ├── Broadcast manager
          ├── Redis Pub/Sub bridge
          ├── Redis Streams
          ├── Durable outbox
          ├── Workflows/sagas
          └── Event store/projections
```

## MVC mapping

| MVC concern     | Events usage                                                        |
| --------------- | ------------------------------------------------------------------- |
| Controller      | Dispatches domain or application events                             |
| Model/aggregate | Records domain events after state transitions                       |
| Service         | Coordinates dispatch, queues, durable publication, or workflows     |
| Listener        | Performs one focused reaction                                       |
| Subscriber      | Groups related listener methods                                     |
| View/Live/WS    | Receives broadcastable events                                       |
| Provider        | Registers listeners, subscribers, contracts, codecs, and subsystems |
| Configuration   | Defines bounds, security, history, Redis, durability, and lifecycle |

The enterprise provider exposes `events`, aliases such as `event.bus`, operational bindings such as `events.health`, and optional subsystems including `events.queue`, `events.scheduler`, `events.workflows`, `events.store`, and `events.projections`. It also installs `app.events()`, `app.event()`, `app.dispatch()`, `app.dispatchAsync()`, and `app.dispatchDeferred()`. 

## Choosing the correct delivery mechanism

| API                  | Scope                |        Waits for listeners |               Survives process loss | Intended use                                         |
| -------------------- | -------------------- | -------------------------: | ----------------------------------: | ---------------------------------------------------- |
| `dispatch()`         | Current process      |                         No |                                  No | Fast local notification                              |
| `dispatchAsync()`    | Current process      |          Yes, sequentially |                                  No | Local work that must finish before continuing        |
| `dispatchDeferred()` | Current process      |                         No |                                  No | Move non-critical work out of the current call stack |
| `EventJobQueue`      | Current process      |        Optional job handle |                                  No | Bounded concurrency, retries, priorities             |
| Redis bridge         | Multiple nodes       | No durable acknowledgement |                                  No | Ephemeral cross-node fan-out                         |
| Redis Streams        | Multiple nodes       |   Consumer acknowledgement |                       Yes, in Redis | At-least-once distributed processing                 |
| Event outbox         | Database + transport |           Publisher-driven |           Yes with persistent store | Business-critical integration events                 |
| Workflow engine      | Application workflow |                        Yes | Only with persistent workflow store | Multi-step work with compensation                    |
| Event store          | Aggregate stream     |                        Yes |        Only with persistent adapter | Event-sourced domains and projections                |

## Listener execution order

For:

```text
order:checkout:completed
```

RawNode executes:

```text
1. order:checkout:completed
2. order:checkout:*
3. order:*
4. matching onPattern() listeners
5. onAny() listeners
```

Higher numeric priority runs first inside each stage. Pattern and catch-all listeners receive the actual event name as their first argument; exact and hierarchical listeners receive only the dispatched arguments. This ordering and the extended dispatch modes are protected by the current compatibility tests. 

## Non-blocking guarantees

`dispatch()` is synchronous and intentionally does not await listener promises. Promise rejections are observed and reported, but execution continues immediately. Use `dispatchAsync()` when the caller must wait.

For sustained workloads, use:

```text
dispatchDeferredWith()  → bounded deferred queue
EventJobQueue           → bounded concurrency and retries
RedisStreamTransport    → durable distributed processing
EventOutbox             → transaction-safe eventual delivery
```

## Framework comparison

| Capability                     | RawNode Events             | Laravel Events               | NestJS event/CQRS patterns      | Fastify hooks               |
| ------------------------------ | -------------------------- | ---------------------------- | ------------------------------- | --------------------------- |
| Primitive runtime dependencies | Node.js + RawNode modules  | PHP framework services       | Framework/integration dependent | Fastify lifecycle           |
| Exact domain events            | Yes                        | Yes                          | Yes                             | Not its main abstraction    |
| Hierarchical wildcards         | Native                     | Limited                      | Integration dependent           | No                          |
| Glob patterns                  | Native                     | Limited                      | Integration dependent           | No                          |
| Async context                  | Native `AsyncLocalStorage` | Request/runtime dependent    | Integration dependent           | Request-scoped hooks        |
| Bounded replay                 | Native                     | Separate concern             | Separate concern                | No                          |
| Redis Pub/Sub bridge           | Native                     | Broadcast/queue integration  | Transport integration           | No                          |
| Durable Streams/outbox         | Native contracts           | Queue/outbox implementation  | CQRS transport dependent        | No                          |
| Workflows and compensation     | Native                     | Usually application packages | Saga/CQRS patterns              | No                          |
| Hot-path specialization        | Yes                        | DX-oriented                  | Abstraction-oriented            | Strong HTTP lifecycle focus |

## 3.1 Basic standalone dispatch

**File**: `examples/events/01-basic.js`

**Payload**:

```js
'use strict';

import { AdvancedEventDispatcher } from '#events';

const events = new AdvancedEventDispatcher({
  profile: 'compat',
});

function welcomeUser(user) {
  console.log(`Welcome ${user.name}`);
}

// on() returns the dispatcher for fluent compatibility.
events.on('user:registered', welcomeUser);

// Synchronous local dispatch.
events.dispatch('user:registered', {
  id: 'user-1001',
  name: 'Ama',
  email: 'ama@example.com',
});

// once() is claimed atomically before invocation.
events.once('application:ready', (application) => {
  console.log(`${application.name} is ready`);
});

events.dispatch('application:ready', { name: 'Mama Africa VIP' });
events.dispatch('application:ready', { name: 'This will not be received' });

// Remove a known listener.
events.off('user:registered', welcomeUser);

await events.close();
```

Use this form for standalone scripts, isolated workers, or tests. In the full framework, resolve the provider-owned dispatcher instead of creating another global application bus.


**Payload**:

```js
'use strict';

export default class OrdersController {
  static dependencies = ['app'];

  constructor(app) {
    this.app = app;
  }

  async store(req, res) {
    const events = this.app.events();

    const order = {
      id: `order-${Date.now()}`,
      userId: req.user?.id || null,
      total: Number(req.body?.total || 0),
      currency: req.body?.currency || 'USD',
      createdAt: new Date(),
    };

    // Fast local notification. This does not await asynchronous listeners.
    events.dispatch('order:created', order);

    // Sequentially await all matching listeners.
    await events.dispatchAsync('order:created:committed', order);

    // Production-safe deferred dispatch with observable admission.
    const admission = events.dispatchDeferredWith(
      {
        coalesce: true,
        key: `analytics:order:${order.id}`,
      },
      'analytics:order:created',
      {
        orderId: order.id,
        userId: order.userId,
        total: order.total,
      },
    );

    if (!admission.accepted) {
      this.app.resolve('logger')?.warn?.(
        'Deferred analytics event was not admitted',
        {
          orderId: order.id,
          reason: admission.reason,
        },
      );
    }

    return res.status(201).json({
      ok: true,
      order,
    });
  }
}
```

Use `dispatchDeferredWith()` rather than plain `dispatchDeferred()` when admission failure, queue overflow, or coalescing matters. Plain `dispatchDeferred()` intentionally returns `undefined`.

## 3.3 Hierarchical events, patterns, catch-all listeners, and priorities

**File**: `examples/events/02-routing.js`

**Anchor**: Locate this exact block:

```text
[new file]
```

**Action**: Replace it with:

**Payload**:

```js
'use strict';

import assert from 'node:assert/strict';
import { AdvancedEventDispatcher } from '#events';

const events = new AdvancedEventDispatcher();
const order = [];

// Higher priority runs first inside the exact-event stage.
events.on(
  'order:checkout:completed',
  () => order.push('exact:high'),
  { priority: 100 },
);

events.on(
  'order:checkout:completed',
  () => order.push('exact:normal'),
);

// Hierarchical wildcard stages.
events.on(
  'order:checkout:*',
  () => order.push('hierarchy:checkout'),
);

events.on(
  'order:*',
  () => order.push('hierarchy:order'),
);

// Glob pattern listener.
// Pattern listeners receive eventName as their first argument.
events.onPattern(
  'order:**',
  (eventName, payload) => {
    order.push(`pattern:${eventName}:${payload.id}`);
  },
);

// Catch-all listener also receives eventName first.
events.onAny(
  (eventName) => {
    if (eventName.startsWith('order:')) {
      order.push('any');
    }
  },
  { priority: -1000 },
);

events.dispatch('order:checkout:completed', {
  id: 'checkout-1001',
});

assert.deepEqual(order, [
  'exact:high',
  'exact:normal',
  'hierarchy:checkout',
  'hierarchy:order',
  'pattern:order:checkout:completed:checkout-1001',
  'any',
]);

console.log(order);

await events.close();
```

Pattern semantics are:

```text
*   matches within one namespace segment
**  crosses namespace segments
?   matches one character inside a segment
```

Examples:

```text
user:*             → user:created
user:**            → user:profile:photo:updated
billing:invoice:?  → billing:invoice:1
```

## 3.4 Disposable handles, fluent registration, and listener scopes

**File**: `examples/events/03-subscriptions.js`


**Action**: Replace it with:

**Payload**:

```js
'use strict';

import { AdvancedEventDispatcher } from '#events';

const events = new AdvancedEventDispatcher();

/*
|--------------------------------------------------------------------------
| Disposable handle
|--------------------------------------------------------------------------
*/

const auditHandle = events.subscribe(
  'billing:invoice:paid',
  async (invoice) => {
    console.log('Auditing invoice', invoice.id);
  },
  {
    priority: 100,
    owner: 'module:billing',
    tags: ['billing', 'audit'],
    timeoutMs: 5_000,
    errorPolicy: 'isolate',
  },
);

console.log(auditHandle.id);
console.log(auditHandle.metadata);

auditHandle.pause();

events.dispatch('billing:invoice:paid', {
  id: 'invoice-1001',
});
// Paused listener is skipped.

auditHandle.resume();

await events.dispatchAsync('billing:invoice:paid', {
  id: 'invoice-1002',
});

auditHandle.dispose();

/*
|--------------------------------------------------------------------------
| Fluent subscription builder
|--------------------------------------------------------------------------
*/

const paymentHandle = events
  .when('payment:captured')
  .priority(200)
  .owner('module:payments')
  .tag('payments', 'critical')
  .timeout(10_000)
  .errorPolicy('fail-fast')
  .listen(async (payment) => {
    console.log('Payment captured', payment.id);
  });

await events.dispatchAsync('payment:captured', {
  id: 'payment-1001',
  amount: 125,
});

paymentHandle.dispose();

/*
|--------------------------------------------------------------------------
| Pattern builder
|--------------------------------------------------------------------------
*/

const domainAudit = events
  .pattern('inventory:**')
  .priority(-100)
  .owner('module:inventory')
  .tag('inventory', 'audit')
  .listen((eventName, payload) => {
    console.log('Inventory audit', eventName, payload);
  });

events.dispatch('inventory:stock:reserved', {
  sku: 'RN-100',
  quantity: 5,
});

/*
|--------------------------------------------------------------------------
| Provider/plugin-owned scope
|--------------------------------------------------------------------------
*/

const scope = events.scope('plugin:recommendations');

scope
  .on('product:viewed', (product) => {
    console.log('Product viewed', product.id);
  })
  .onPattern('cart:**', (eventName, payload) => {
    console.log('Cart activity', eventName, payload);
  })
  .onAny((eventName) => {
    if (eventName.startsWith('recommendation:')) {
      console.log('Recommendation event', eventName);
    }
  });

scope.pause();
scope.resume();

// Removes every listener registered through this scope.
const removed = scope.dispose();

console.log({ removed });

domainAudit.dispose();
await events.close();
```

`on()` remains fluent and returns the dispatcher. `subscribe()` returns the disposable `ListenerHandle`. This distinction preserves existing behavior while giving providers, plugins, and tests precise ownership.

```js
  tenantId: 'tenant-africa',
  actorId: 'admin-100',
  traceId: 'trace-1001',
  source: 'POST /register',
});

await events.run(requestContext, async () => {
  const event = new UserRegistered(
    {
      id: 'user-1001',
      email: 'ama@example.com',
      firstName: 'Ama',
      lastName: 'Mensah',
    },
    {
      meta: {
        registrationMethod: 'email',
      },
    },
  );

  await events.dispatchAsync(event);

  const child = events.childContext({
    source: 'send-welcome-message',
  });

  await events.run(child, async () => {
    await events.dispatchAsync(
      'mail:welcome:requested',
      {
        userId: event.payload.userId,
        email: event.payload.email,
      },
    );
  });
});

await events.close();
```

```js
'use strict';

export function installEventsShutdown(app) {
  let closing = false;

  const shutdown = async (signal) => {
    if (closing) return;
    closing = true;

    const logger = app.resolve('logger');
    const manager = app.resolve('events.manager');

    logger?.info?.('Closing RawNode Events', {
      signal,
    });

    try {
      await manager.close({
        drainOutbox: true,
      });

      logger?.info?.('RawNode Events closed', {
        signal,
      });
    } catch (error) {
      process.exitCode = 1;

      logger?.error?.(
        'RawNode Events shutdown failed',
        error,
      );
    }
  };

  process.once('SIGTERM', () => {
    void shutdown('SIGTERM');
  });

  process.once('SIGINT', () => {
    void shutdown('SIGINT');
  });

  return shutdown;
}
```

In a complete RawNode application, the application bootstrapper should normally invoke provider teardown. Avoid closing the provider-owned dispatcher separately from the provider manager.

```js
    async (envelope, message) => {

        ...(envelope.ctx || {}),

        remote: true,
        originTransport: 'redis-stream',
        originNode: envelope.node,
        envelopeId: envelope.id,
        hop: envelope.hop,
        source: stream.stream,

        handled: true,
        streamId: message.id,

      };
    },
    {
      recover: true,
    },
```

```js
export async function runCheckoutWorkflow(app, input) {
  const workflows = app.resolve('events.workflows');

  workflows.define(
    'checkout',
    [
      {
        name: 'reserve-inventory',

        retries: 2,
        retryDelayMs: 250,
        timeoutMs: 5_000,

        async run(context) {
          const inventory = app.resolve('inventory');

          const reservation = await inventory.reserve(
            context.input.items,
            {
              signal: context.signal,
            },
          );

          context.state.reservationId = reservation.id;

          return reservation;
        },

        async compensate(context) {
          const inventory = app.resolve('inventory');

          await inventory.release(
            context.state.reservationId,
            {
              signal: context.signal,
            },
          );
        },
      },

      {
        name: 'capture-payment',

        retries: 1,
        timeoutMs: 15_000,

        async run(context) {
          const payments = app.resolve('payments');

          const payment = await payments.capture({
            amount: context.input.total,
            currency: context.input.currency,
            customerId: context.input.customerId,
            idempotencyKey: `checkout:${context.id}`,
          });

          context.state.paymentId = payment.id;

          return payment;
        },

        async compensate(context) {
          const payments = app.resolve('payments');

          if (context.state.paymentId) {
            await payments.refund(
              context.state.paymentId,
              {
                reason: 'checkout-compensation',
              },
            );
          }
        },
      },

      {
        name: 'create-order',

        timeoutMs: 10_000,

        async run(context) {
          const orders = app.resolve('orders');

          return orders.create({
            ...context.input,
            reservationId: context.state.reservationId,
            paymentId: context.state.paymentId,
          });
        },
      },
    ],
    {
      version: 1,
      compensateOnFailure: true,
      replace: true,
    },
  );

  const events = app.resolve('events');
  const current = events.getContext();

  return workflows.start(
    'checkout',
    input,
    {
      correlationId: current?.correlationId,
      meta: {
        tenantId: current?.tenantId,
        actorId: current?.actorId,
      },
    },
  );
}
```

```js
'use strict';

import {
  AggregateRoot,
  Event,
} from '#events';

export class AccountOpened extends Event {
  static eventName = 'account:opened';

  constructor(payload, options = {}) {
    super(payload, options);
  }
}

export class MoneyDeposited extends Event {
  static eventName = 'account:money:deposited';

  constructor(payload, options = {}) {
    super(payload, options);
  }
}

export class MoneyWithdrawn extends Event {
  static eventName = 'account:money:withdrawn';

  constructor(payload, options = {}) {
    super(payload, options);
  }
}

export default class BankAccount extends AggregateRoot {
  constructor(id) {
    super(id);

    this.ownerId = null;
    this.currency = null;
    this.balance = 0;
    this.opened = false;
  }

  open(ownerId, currency = 'USD') {
    if (this.opened) {
      throw new Error('Account is already open');
    }

    return this.record(
      new AccountOpened({
        accountId: this.id,
        ownerId,
        currency,
      }),
    );
  }

  deposit(amount) {
    if (!(amount > 0)) {
      throw new Error('Deposit must be positive');
    }

    return this.record(
      new MoneyDeposited({
        accountId: this.id,
        amount,
      }),
    );
  }

  withdraw(amount) {
    if (!(amount > 0)) {
      throw new Error('Withdrawal must be positive');
    }

    if (amount > this.balance) {
      throw new Error('Insufficient balance');
    }

    return this.record(
      new MoneyWithdrawn({
        accountId: this.id,
        amount,
      }),
    );
  }

  applyAccountOpened(payload) {
    this.ownerId = payload.ownerId;
    this.currency = payload.currency;
    this.opened = true;
  }

  applyAccountMoneyDeposited(payload) {
    this.balance += payload.amount;
  }

  applyAccountMoneyWithdrawn(payload) {
    this.balance -= payload.amount;
  }
}
```
