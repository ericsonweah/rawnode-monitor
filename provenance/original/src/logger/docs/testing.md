# Testing

`LoggerRecorder`, `MemoryTransport`, `FakeClock`, and `createLoggerHarness` provide deterministic application tests without intercepting global console methods.

The package test suite covers the v1 contract, structured runtime, ordering, backpressure, redaction, hostile serialization, channels, providers, CLI, file/audit lifecycle, network transports, inspector controls, process listeners, open handles, retries, ownership, and TypeScript consumers.
